# ระบบยืม-คืนอุปกรณ์

## ลิงก์สำคัญ

| ลิงก์ | คำอธิบาย |
|---|---|
| [📋 แบบฟอร์มยืมอุปกรณ์](https://pengthanason.github.io/equipment-dashboard/form.html) | ผู้ยืมกรอกฟอร์มที่นี่ |
| [🖥️ หน้าแดชบอร์ด (Admin)](https://pengthanason.github.io/equipment-dashboard/) | แอดมินเข้าดูและจัดการข้อมูล |

---

## วิธีใช้งาน

### สำหรับผู้ยืมอุปกรณ์
1. เปิด [แบบฟอร์มยืมอุปกรณ์](https://pengthanason.github.io/equipment-dashboard/form.html)
2. กรอก ชื่อ-นามสกุล, แผนก, วันยืม, วันคืน
3. เพิ่มรายการอุปกรณ์ที่ต้องการยืม (กดปุ่ม **+ เพิ่มรายการ** ได้หลายชิ้น)
4. กด **ส่งคำขอยืม** — ข้อมูลจะขึ้นที่แดชบอร์ดอัตโนมัติภายใน 10 วินาที

### สำหรับแอดมิน
1. เปิด [หน้าแดชบอร์ด](https://pengthanason.github.io/equipment-dashboard/)
2. Login ด้วย username: `admin` / password: `admin`
3. ดูรายการยืม-คืน, ค้นหา, กรองสถานะได้
4. กดปุ่ม **แก้ไข** เพื่อเปลี่ยนสถานะ, วันคืน, หรือชื่ออุปกรณ์

---

## การคืนอุปกรณ์

แอดมินเข้าหน้าแดชบอร์ด แล้วกด **แก้ไข** บนรายการที่ต้องการ  
จากนั้นเปลี่ยน **สถานะ** จาก `กำลังยืม` เป็น `คืนแล้ว` แล้วกด **บันทึก**
