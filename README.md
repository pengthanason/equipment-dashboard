## วิธีใช้งาน

### สำหรับผู้ยืมอุปกรณ์
1. เปิด [แบบฟอร์มยืมอุปกรณ์](https://forms.gle/81x294ZBgmiN5ox47)
2. กรอก ชื่อ, นามสกุล, อุปกรณ์ที่ต้องการยืม, วันยืม, วันคืน, หมายเหตุ
3. กด **ส่ง** — ข้อมูลจะขึ้นที่แดชบอร์ดอัตโนมัติภายใน 30 วินาที

### สำหรับแอดมิน
1. เปิด [หน้าแดชบอร์ด](https://pengthanason.github.io/equipment-dashboard/)
2. Login ด้วย username: `admin` / password: `admin`
3. ดูรายการยืม-คืน, ค้นหา, กรองสถานะได้
4. กดปุ่ม **แก้ไข** เพื่อเปลี่ยนสถานะ, วันคืน, หรือชื่ออุปกรณ์

---

## การคืนอุปกรณ์

ตอนนี้แอดมินต้องเข้าหน้าแดชบอร์ด แล้วกด **แก้ไข** บนรายการที่ต้องการ  
จากนั้นเปลี่ยน **สถานะ** จาก `กำลังยืม` เป็น `คืนแล้ว` แล้วกด **บันทึก**
